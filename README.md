# СИСТЕМА УЧЁТА ЛЕКАРСТВ В АПТЕКЕ  
## ПРЕДМЕТНАЯ ОБЛАСТЬ:
В системе будет учитываться название, размер, необходимость рецепта от врача при выдаче, расположение товара и его тип

## Цели системы:
Система может показывать возможность выдачи лекарства при запросе покупателя, предупреждать о необходимости предъявить рецепт от врача перед выдачей, заносить новые лекарства на свободные места и удалять старые товары.

## ПОЛЬЗОВАТЕЛИ СИСТЕМЫ:
Покупатель. Им может быть любой пользователь зашедший через приложение. Может посмотреть наличие товара перед тем, как идти в аптеку.
Продавец в аптеке. Может посмотреть наличие товара и узнать его расположение, а также вносить новые товары в базу данных 

## ФУНКЦИИ СИСТЕМЫ:  
1)	Система должна показывать пользователю наличие требуемого товара в аптеке и сообщать о необходимости рецепта от врача.
2)	Система должна сообщить продавцу нахождение товара.
3)	Система должна записывать новые товары в базу данных и направлять их на свободные места.
4)  Система должна уметь удалять товары из базы данных.

## Описание системы:
При входе пользователь происходит авторизацию, по итогам которой пользователю присуждается роль, от которой будут зависеть его возможности.
У гостя есть возможность только посмотреть наличие требуемого товара и узнать необходимость рецепта от врача для его получения.
Продавец имеет расширенные возможности, а именно:
1) Просмотр наличия товара, необходимость рецепта, расположение товара на складе
2) Внесение и удаление товара из базы данных
